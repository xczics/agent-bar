# 未发布（计划为 v0.0.3）

## 改进

- **后台任务通知显示成人话**：Claude Code 的后台任务（后台命令、子 agent 等）结束时，会往对话里注入一条 `<task-notification>…` 消息。以前列表第二行会原样显示这串标记文本，现在显示成“后台任务完成：<任务描述>”；失败时显示“后台任务失败”，被终止时显示“后台任务已停止”。灯的状态不变，仍然是“运行中”。

## 修复

- **子 agent 冒用主 agent 的灯**：Claude Code 派出去的子 agent（Task / Agent 工具，例如在 `.claude/worktrees/` 里工作的）和主会话共用同一个 session_id，以前它们的事件会改写主会话的项目名（显示成 `agent-ae31…`），第二行显示的工具名和状态也被子 agent 带着走。现在浮窗只显示主 agent 的状态：
  - 带 `agent_id` 的子 agent 事件会被忽略，只保留权限请求（会卡住整个会话）；
  - 会话的 cwd 和项目名以第一次记录的为准，不会再被改写。
