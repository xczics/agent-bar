# 未发布（计划为 v0.0.3）

## 新功能

- **灯可以放进菜单栏**：右键菜单新增“放在：桌面浮窗 / 菜单栏”，选哪里就去哪里，并会记住选择。在菜单栏里，每个会话是一个彩色小圆点（最多 8 个，多的显示 `+N`）；点开是会话列表，点某一行会标为已读并跳到 VS Code。

## 改进

- **后台任务通知显示成人话**：Claude Code 的后台任务（后台命令、子 agent 等）结束时，会往对话里注入一条 `<task-notification>…` 消息。以前列表第二行会原样显示这串标记文本，现在显示成“后台任务完成：<任务描述>”；失败时显示“后台任务失败”，被终止时显示“后台任务已停止”。灯的状态不变，仍然是“运行中”。

## 修复

- **子 agent 冒用主 agent 的灯**：Claude Code 派出去的子 agent（Task / Agent 工具，例如在 `.claude/worktrees/` 里工作的）和主会话共用同一个 session_id，以前它们的事件会改写主会话的项目名（显示成 `agent-ae31…`），第二行显示的工具名和状态也被子 agent 带着走。现在浮窗只显示主 agent 的状态：
  - 带 `agent_id` 的子 agent 事件只当作心跳：刷新主会话的“最后更新时间”，不改状态、详情和项目名。这样主 agent 等一个跑得很久的子 agent 时，不会被误判成“无响应?”。权限请求例外，照常让灯变红，因为它会卡住整个会话；
  - 会话的 cwd 和项目名以第一次记录的为准，不会再被改写。
- 开启 `AGENT_STATUS_DEBUG=1` 时，浮窗写调试日志会触发自己重新扫描目录，形成每约 0.1 秒一次的循环；已修复（只影响调试模式）。
- **拔掉显示器后浮窗消失**：浮窗原来在外接显示器上时，拔掉显示器后它会停在已经不存在的屏幕上，看不见也找不回来。现在显示器插拔或分辨率变化时，浮窗会被挪回主屏右上角；显示器插回来后，会回到你上次拖到的位置。再次运行 `agent-bar` 时，也会把跑到屏幕外的浮窗拉回来。
