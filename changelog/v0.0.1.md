# v0.0.1 — 2026-10-21

第一个版本，目前只支持 macOS（universal：arm64 + x86_64，macOS 11 及以上）。

## 新功能

- **agent-status-hook**：由 Claude Code hooks 调用，把每个会话的状态写到 `~/.claude/agent-status/<session_id>.json`。
  - 实现了设计文档里的全部 7 个事件映射，包括“已回复之后收到的 Notification 不改状态、不重置已读”这一条。
  - 用 `flock` 文件锁加原子 rename 写入；50 个进程并发写同一个会话时，文件始终是合法 JSON。
  - 任何情况下都以退出码 0 退出，stdout 不输出任何内容；只接受由字母、数字、`-`、`_` 组成的 session_id，防止路径穿越；按 Unicode 字符截断，不会切断多字节字符。
  - 单次运行中位数约 **1.2 ms**（hyperfine 测量，M 系列 Mac）。
  - 内置 `install-hooks` / `uninstall-hooks` 子命令，用来合并或移除 settings.json 里的 hooks。
- **agent-bar（macOS）**：常驻置顶的非激活 NSPanel。
  - **紧凑模式**（默认）：每个会话一个发光的灯，一行最多 6 个、最多 3 行，超出部分显示 `+N`。灯上方显示项目简称，下方显示状态简写，两者都可以单独关闭。未读的灯有扩散光环（等你确认扩散得快，已回复扩散得慢），动画交给 Core Animation，在渲染服务里运行。单击灯会标为已读，并跳到对应项目的 VS Code 窗口；右侧的 ⌄ 按钮（或单击空白处）展开列表。
  - **展开列表**：项目名、“状态 · 已过时间”、未读的“新”徽标、当前在做的事；单击标为已读，双击打开 VS Code。
  - 用 FSEvents 监听目录变化，去抖 100 ms，文件变化后约 **110 ms** 重绘。计时器只在显示内容真的变化时才重绘。
  - 默认配色：运行中为绿色，空闲为熄灭的暗绿色，已回复为黄色，等你确认为红色，无响应为灰色。
  - **设置窗口**：可以自定义每种状态的颜色（支持恢复默认），并设置显示选项、无响应阈值和开机自启。
  - 右键菜单：展开/收起、全部标为已读、清理空闲/无响应记录、紧凑模式、开机自启（LaunchAgent）、设置…、退出。
  - **自动发现会话**：启动时以及每 10 分钟读取 Claude Code 的会话登记 `~/.claude/sessions/`，给还活着、但没有状态记录的会话补一条记录。浮窗重启、或会话早于 hook 安装时，都不用手动添加。
  - 整个浮窗任意位置都能拖动；只有原地按下又松开才算点击。
  - 单实例；窗口位置、阈值和模式保存在 `bar.ini`。
  - 命令行参数：`--list`、`--snapshot`、`--autostart on|off`、`--version`。
- **接入 prompt**：README 里有一段可以直接发给 agent 的 prompt，由 agent 自动完成下载、校验和安装。
- **安装与卸载脚本**：先备份 settings.json，再合并 hooks，重复运行不会产生重复条目，会替换 Python 原型 `status_hook.py` 的条目；卸载只移除本项目的条目。
- **测试**：38 个 core 单元测试（覆盖映射表每一行、排序规则、settings 合并、文件存储），以及 hook 验收、浮窗冒烟、空闲资源三个脚本。
- **CI/CD**：GitHub Actions 在 macOS 和 Linux 上构建并测试；推送 `v*` tag 时自动打包 universal 二进制并发布 Release。

## 已知问题

- 浮窗的物理内存占用约 14 MB，没有达到设计目标的 10 MB 以内。在同一台机器上，一个最小的空白 Cocoa 面板就要约 10 MB，多出的部分主要来自中文字体和文字排版缓存。
- 设计文档中的部分验收项还需要人工确认：同时开两个 VS Code 窗口时的显示、浮窗空闲 1 小时的 CPU 实测（见 Handoff.md）。
