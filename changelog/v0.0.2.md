# v0.0.2 — 2026-10-21

## 新功能

- **桌面（Space）行为可选**：设置窗口和右键菜单新增“在所有桌面显示”开关。
  - 关闭（**新的默认值**）：浮窗是普通窗口，属于某一个桌面。四指上划进入调度中心后，可以拖动它，也可以把它拖到别的桌面。
  - 打开（v0.0.1 的行为）：浮窗出现在每个桌面上，在调度中心里固定不动，不能拖。
  - 两种模式下，浮窗都能显示在全屏应用之上（用户已实测）。
- **`agent-bar attach`**：agent 在自己的 shell 里运行这一条命令，就能把自己挂到浮窗上。它会沿进程链认出所属会话、补登记、检查 hooks，浮窗没运行时把它独立启动起来。README 新增对应的“挂载 prompt”；安装 prompt 的最后一步也改为运行 attach。
- 教程新增“支持哪些 agent”一节。
- **adapter 层**：hook 先通过 adapter 把各种 agent 的原始事件转换成统一的内部事件。目前内置 Claude Code 这一个 adapter；其他 agent 的 hook 调用 `agent-status-hook --agent <名字>`。状态文件新增 `agent` 字段，旧文件没有这个字段时按 Claude Code 处理，非 Claude Code 的会话会在列表和 tooltip 里标出 agent 名。
- **`agent-status-hook emit`**：不用拼 JSON，直接上报一个事件，适合调试和写适配脚本。
- **开发指南**：新增 `docs/development.md`，README 里有摘要；重点讲如何为你喜欢的 agent 添加支持。
- **已读的回复变暗**：“已回复”被看过之后（点了灯，或者已经发了下一条消息），灯从黄色变成暗绿（按“空闲”显示和排序），只有没看过的回复才是黄色。“等你确认”看过后仍是红色。
